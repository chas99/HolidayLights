<h1>Holiday Lights</h1>

 ### [YouTube Demonstration](https://youtube.com/shorts/55U0yq9c6ag)

<h2>Description</h2>
Project consists of a breadboard, one RGB LED with three 220 Ohm resistors, three diode LEDs with three 220 Ohm resistors, jumper wires, and an Arduino board. Also, Arduino code that outputs music syncing blinking LEDs.
<br />


<h2>Languages and Utilities Used</h2>

- <b>Arduino</b>
- <b>Arduino IDE</b> 

<h2>Environments Used </h2>

- <b>Windows 10</b> (21H2)
